## 二、项目定位（一句话）
面向**来京务工人员（尤其流动女性）**的信息服务与智能推荐系统：
以「**公益组织库 + 政策知识库**」为数据底座，用**知识图谱**串联「人—需求—组织—活动—政策」，实现智能问答、组织/活动推荐、政策科普。

## 三、需求分析
- **目标用户**：外地来京务工人员，重点关注流动女性（家政、餐饮、零售、制造业女工等）
- **核心痛点**：① 不知道身边有哪些公益组织、能提供什么；② 不知道有哪些活动、怎么参加；③ 政策信息分散、口径不一、看不懂
- **典型测试问题**：
  - 组织类：「XXX 相关公益组织，往年办过哪些女性文艺活动？流程是什么？」→ 答案落到**具体组织 + 组织介绍**
  - 政策类：「外地务工人员在北京怎么申请免费法律援助？」「孩子在京上学需要什么材料？」→ 答案**准确、可溯源**

## 五、设计思路
- **知识图谱 Schema**
  - 实体：组织 / 活动 / 政策 / 服务 / 地点 / 人群标签
  - 关系：举办、服务、适用于、位于、需材料、发布…
- **问答引擎**：LLM + 检索增强（RAG）／图谱查询（组织类走图谱，政策类走权威文档库）
- **个性化推荐**：按人群标签（性别 / 职业 / 有无子女 / 主要诉求）匹配组织与活动

## 六、功能模块
