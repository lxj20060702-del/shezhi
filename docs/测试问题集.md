# 「她知」功能A · 测试问题集（T9，10 题）

> 用途：问答链路评测 + 设计文档/演示视频引用。
> 政策类答案验收标准：**与官方口径一致、标注发布机构与日期、可溯源**；组织类必须落到**具体组织 + 服务/活动介绍**。

## 一、政策类（6 题）

| # | 测试问题 | 验收要点（答案必须包含） | 权威来源 |

## 三、评测方法

1. 自动化（路由 + 检索命中）：
   ```bash
   pip install jieba streamlit
   python tests/eval_qa.py
   ```
   输出路由准确率、检索命中率，结果写入 `tests/eval_result.json`。
2. 人工（大模型答案质量）：配好 GLM Key 后 `streamlit run app.py`，逐题核对上表验收要点，
   检查引用标记是否被清理、「查看依据」中来源链接是否可点开。
